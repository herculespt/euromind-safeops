# Governance

EuroMind SafeOps starts as a **single-maintainer project** led by Sérgio Ribeiro (`herculespt`).

Decisions are discussed publicly in GitHub Issues and pull requests. The maintainer reviews scope, security risk, compatibility and test evidence before merging. Technical disagreements should be documented with tradeoffs; no one is entitled to merge access simply by submitting contributions.

The project may add trusted maintainers once regular outside contributors exist. Such appointments and any changes to contribution rules will be documented publicly. The maintainer uses pull requests and the GitHub `quality-gate` CI result before merging. Configure branch protection as described in [the maintainer guide](docs/MAINTAINER_GUIDE.md). Release steps are documented in [the release procedure](docs/RELEASING.md); a tagged release must be independently verified before being announced.

There are currently **no claimed outside maintainers, adopters or contributors**.
